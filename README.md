# KANBAN LAK

Een zelfstandige, lichte kanbanwebsite voor het opvolgen van acties.

## Lokaal gebruiken

Open `index.html` in een browser. Acties worden lokaal opgeslagen in `localStorage`.

## GitHub Pages

De site is volledig statisch en kan rechtstreeks vanuit de `main`-branch worden gepubliceerd via **Settings → Pages → Deploy from a branch**.
